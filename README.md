# AutoHeal-AI-Predictive-Maintenance
AI-powered autonomous predictive maintenance system that detects anomalies, prevents failures, and takes real-time corrective actions.


### 🧠 AI-powered Autonomous Failure Detection & Prevention

---

## 🔍 Overview

**AutoHeal AI** is an intelligent industrial monitoring system that:

* Detects anomalies in real-time
* Predicts machine failures before they occur
* Automatically takes corrective actions
* Explains decisions using an AI assistant

👉 It transforms **reactive maintenance → predictive & autonomous maintenance**

---

## ⚡ Key Features

* 🧠 **AI Anomaly Detection**

  * Detects overheating, high vibration, voltage spikes

* 🔮 **Failure Prediction**

  * Estimates time-to-failure using sensor trends

* ⚙️ **Autonomous Actions**

  * Cooling system activation
  * Load reduction
  * Emergency shutdown

* 📊 **Real-Time Dashboard**

  * Live sensor telemetry (temperature, vibration)
  * Machine health & risk levels

* 💬 **AI Assistant**

  * Explains:

    * “Is the machine safe?”
    * “What happened?”
    * “What action was taken?”

* 🧪 **Failure Simulation**

  * Inject anomalies:

    * Overheating
    * High Vibration
    * Voltage Spike

* 📄 **Reports**

  * Download maintenance logs (CSV)
